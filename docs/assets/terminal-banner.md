# Terminal banner

[Editable source](terminal-banner.svg) · [README image](terminal-banner.png)

The pixel wordmark and terminal layout were drawn for this repository. The sprite pair was generated from supplied character references using this direction: a cobalt terminal robot beside a warm apricot pixel critter with raised pincers, with clear silhouettes and no text or scenery. The SVG embeds the sprite and the README uses a static PNG export.
