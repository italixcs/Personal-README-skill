# Personal README 0.1.0 release candidate

Creates, redesigns and audits GitHub profile READMEs. The workflow verifies public positioning, checks existing profile assets, reviews recently published projects, and validates local buttons, stack icons, and public metrics. The package consists of Markdown instructions, three optional references and the license.

Start with the [installation guide](installation.md) or use the installable folder with an agent that can read `SKILL.md` directly. See the [validation report](validation.md) for the package scan, comparison results and host coverage.

The candidate uses the MIT license. The [Italixcs example](italixcs-example.md) demonstrates a terminal theme with local artwork and a dated statistics snapshot.
